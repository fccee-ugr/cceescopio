La Facultad en los ranking

Posición de la Universidad de Granada en las áreas de la Facultad de Ciencias Económicas y Empresariales: Economía, Empresa, Finanzas y Turismo

Fecha de modificación

18 de noviembre de 2026

Los rankings internacionales por disciplinas permiten situar la investigación y la docencia de la UGR en las áreas de la Facultad: Economía, Empresa, Finanzas y Turismo. Esta página recoge las posiciones publicadas por la Unidad de Analítica de la UGR en los tres rankings internacionales más citados (ARWU o Ranking de Shanghái, QS y THE). Las posiciones mundiales del Ranking de Shanghái por materias se han completado y contrastado con la web oficial de ShanghaiRanking; en las ediciones que solo figuran allí, los puestos en España y Andalucía se han calculado a partir de la lista oficial.

Cómo leer las posiciones. Los rankings publican intervalos de posiciones (por ejemplo, 151-200) a partir de cierta posición mundial. La columna España indica el puesto, o el intervalo de puestos, de la UGR entre las universidades españolas, y la columna Andalucía, entre las andaluzas.

rk = FileAttachment("data/rankings_ugr_areas.csv").csv({typed: false})

Evolución en el tiempo

Posición mundial de cada área en todas las ediciones disponibles. La banda indica el intervalo publicado y la línea une sus centros; más arriba es mejor. El Ranking de Shanghái por materias tiene la serie más larga: desde 2017-2019, según el área. Las ediciones que no figuran en las fuentes consultadas aparecen como un hueco.

viewof rkEvo = Inputs.select([...new Set(rk.map(d => d.ranking))], {label: "Ranking", value: "ARWU (Shanghai)"})
{
  const iv = (s) => { const m = String(s ?? "").match(/(\d+)\s*[-–]\s*(\d+)/); if (m) return [+m[1], +m[2]]; const n = parseInt(s); return Number.isFinite(n) ? [n, n] : null; };
  const f = rk.filter(d => d.ranking === rkEvo).map(d => ({...d, anio: +d.edicion, iv: iv(d.mundial)})).filter(d => d.iv && d.anio).sort((a, b) => a.anio - b.anio);
  const areas = [...new Set(f.map(d => d.area))];
  const anios = d3.range(d3.min(f, d => d.anio), d3.max(f, d => d.anio) + 1);
  // Para que la línea se corte en los años sin dato
  const conHuecos = areas.flatMap(a => anios.map(y => { const d = f.find(x => x.area === a && x.anio === y); return d ? {...d, c: d3.mean(d.iv)} : {area: a, anio: y, c: NaN}; }));
  const col = {domain: areas, range: ["#B5175F", "#F29200", "#3C3C3B", "#1F77B4", "#2CA02C", "#9467BD", "#8C564B"].slice(0, areas.length), legend: true};
  return Plot.plot({
    title: `La UGR en ${rkEvo}: evolución de la posición mundial por área`,
    height: 440, marginLeft: 55, marginRight: 20,
    x: {label: "Edición", tickFormat: "d", ticks: anios, domain: [anios[0] - 0.3, anios.at(-1) + 0.3]},
    y: {label: "↑ Posición mundial (1 = la mejor)", reverse: true, grid: true, domain: [0, Math.ceil(d3.max(f, d => d.iv[1]) / 100) * 100]},
    color: col,
    marks: [
      Plot.areaY(conHuecos, {x: "anio", y1: d => d.iv ? d.iv[0] : NaN, y2: d => d.iv ? d.iv[1] : NaN, fill: "area", fillOpacity: 0.12, z: "area"}),
      Plot.line(conHuecos, {x: "anio", y: "c", stroke: "area", strokeWidth: 2.5, z: "area"}),
      Plot.dot(f, {x: "anio", y: d => d3.mean(d.iv), fill: "area", r: 5, tip: true,
        title: d => `${d.area} · ${d.ranking} ${d.edicion}\nMundo: ${d.mundial}${d.espana ? `\nEspaña: ${d.espana}` : ""}\nFuente: ${d.fuente}`}),
      Plot.text(f.filter(d => d.anio === d3.max(f.filter(x => x.area === d.area), x => x.anio)), {x: "anio", y: d => d3.mean(d.iv), text: "mundial", dx: 10, textAnchor: "start", fill: "area", fontSize: 10})
    ]
  });
}

En gráficos

Cada barra es el intervalo de posiciones que publica el ranking (por ejemplo, 151-200); el punto marca su centro. Más a la izquierda es mejor. Se compara la edición más reciente de cada ranking con la anterior.

rkIntervalo = (s) => { const m = String(s ?? "").match(/(\d+)\s*[-–]\s*(\d+)/); if (m) return [+m[1], +m[2]]; const n = parseInt(s); return Number.isFinite(n) ? [n, n] : null; }
rkGraf = {
  const out = [];
  for (const g of d3.groups(rk, d => `${d.ranking} · ${d.area}`)) {
    const ed = [...new Set(g[1].map(d => d.edicion))].sort().reverse();
    g[1].forEach(d => { const k = ed.indexOf(d.edicion); if (k > 1) return;
      out.push({etiqueta: g[0], ranking: d.ranking, area: d.area, edicion: d.edicion, cual: k === 0 ? "Edición más reciente" : "Edición anterior",
        mundo: rkIntervalo(d.mundial), espana: rkIntervalo(d.espana), txtM: d.mundial, txtE: d.espana}); });
  }
  return out;
}

      Plot.dot(d, {x: x => d3.mean(x[rkEje]), y: "etiqueta", dy: desplaza(cual), fill: "white", stroke: "cual", r: 3.5,

Rankings generales de la UGR

Rankings internacionales (ARWU, QS, THE, Leiden, CWUR, URAP, NTU, SCImago, Webometrics, Nature Index, UI GreenMetric, entre otros) y nacionales (U-Ranking, CYD, Observatorio IUNE, El Mundo, Forbes): analitica.ugr.es/rankings.

Para la investigación. Los rankings por disciplinas se basan sobre todo en la producción y el impacto de las publicaciones (artículos en revistas indexadas, citas, colaboración internacional). Publicar en revistas de calidad y con coautoría internacional mejora la posición de la UGR en las áreas de la Facultad.
